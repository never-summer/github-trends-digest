Главные сдвиги

01Память агента — главный рост недели

hindsight набрал за 7 дней +17.4k из +20.6k за месяц: почти весь месячный рост пришёлся на последнюю неделю. Проект делает ставку не на хранение истории диалога, а на то, чтобы агент учился: операции retain, recall, reflect, банки памяти, MCP-сервер и встроенный Python-режим без сервера. У WeKnora тоже есть межсессионная память с подтверждёнными пользователем фактами.

02Управлять не агентом, а их командой

paperclip (+12.9k за неделю из +14.6k за месяц) подаёт агентов как сотрудников компании: цели, оргструктура, бюджеты, учёт затрат и аудит работы из одного дашборда. orca решает ту же задачу ближе к коду: один промпт на несколько агентов, у каждого свой git worktree, сравнение и слияние лучшего результата, управление с телефона.

03Агентам строят рабочие среды

univer называет себя Office Harness: SDK таблиц, документов и презентаций с формульным движком, одним API в браузере и на Node.js, где люди и агенты работают в одних файлах. CLI-Anything делает CLI для произвольного софта, чтобы им пользовались агенты. В месячном топе к ним добавляется hyperframes — рендер HTML в видео, рассчитанный на агентов.

04Skills держат месяц, но не неделю

Половина месячного топа — skills для coding-агентов: archify (диаграммы), ponytail (меньше кода), i-have-adhd (короткие ответы), плюс harness-оптимизатор ECC. В недельный топ-10 из этой волны попал только дизайн-skill impeccable, а неделю возглавили инфраструктурные проекты: память, оркестрация, офисный SDK.

05Вендоры публикуют отраслевые агенты

financial-services от Anthropic — референсные агенты, skills и коннекторы данных для инвестбанкинга, equity research, private equity и управления благосостоянием. Один источник ставится как плагин Cowork или разворачивается через Managed Agents API, а любой результат оставлен на подпись человеку.

06Локальное как аргумент

VoiceStudio (+12.7k) продаёт себя как полностью локальную замену ElevenLabs: клонирование голоса, дубляж, диктовка и транскрибация на своём железе, удалённые сервисы опциональны, есть локальный API и MCP для агентов.

07Первый автоматический выпуск

Сравнивать пока не с чем: это первый выпуск по срезам GitHub Trending. Квартальный топ сейчас совпадает с недельным, потому что в квартале один срез; со следующей недели он начнёт накапливаться.

Что может пригодиться аналитической платформе

Память для Text2SQL-агента

hindsight можно примерить к запоминанию того, что пользователи подтвердили о схемах, метриках и типовых запросах. Есть встроенный Python-режим без отдельного сервера и MCP-сервер; стоит проверить, какие LLM и хранилища он требует для работы в закрытом контуре.

Ревью SQL и кода пайплайнов своей моделью

open-code-review работает с любым настроенным endpoint модели, читает diff и оставляет построчные замечания; во встроенных правилах есть SQL injection. Авторы сознательно ставят точность выше полноты — меньше шума в ревью.

Таблицы и документы внутри BI

univer в README прямо называет сценарий встраивания таблиц и документов в BI-процессы и внутренние инструменты, а обработку книг — на сервере той же архитектурой. Кандидат для редактируемых выгрузок и отчётов рядом с дашбордами.

Документация платформы как база знаний

WeKnora объединяет RAG, агента и вики над одними документами, синхронизируется с Confluence и GitLab и отдаёт встроенный MCP-сервер. Годится как ориентир для поиска по документации и регламентам платформы.

Диаграммы потоков данных из описания

archify строит интерактивные диаграммы архитектуры и data-flow в самодостаточном HTML, в том числе по коду репозитория. Может пригодиться для схем лейкхауса и lineage в документации.

Бюджеты и аудит агентов команды

paperclip показывает, как может выглядеть учёт затрат, бюджеты и аудит работы агентов, когда их у команды много. Пока на радар — как образец модели управления, а не готовый инструмент.

Можно пропустить: gods-eye-view — 3D-глобус с публичными данными, к аналитической платформе не относится; ai-engineering-from-scratch и OpenMAIC — обучение и генерация курсов; VoiceStudio — только если нужен голос.
