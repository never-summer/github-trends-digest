Главные сдвиги

01Реверс-инжиниринг выдохся

rea после +229.3k неделей раньше выпал из недельного топа: в квартальной сумме у него те же ≈356k, что и неделю назад. Ушли из недели и ghidra, и AnyPS5. Прошлый вывод «не разовый всплеск» не подтвердился. В месячном топе ghidra ещё растёт: с +12.0k до +14.8k.

02Безопасность агентов — на первом месте

security-audit-skill неделю назад был только в месячном топе, теперь он первый за неделю (+15.1k), а за месяц вырос с +19.1k до +24.6k. Тренд прошлого выпуска подтвердился. При этом OpenShell из месячного топа выпал.

03Неделя harness и оркестрации

Девять из десяти в недельном топе — новые, остался только hyperframes. Оркестрация: orca (+9.6k) запускает агентов параллельно, каждого в своём git worktree, с ревью диффов и мобильным клиентом. Harness: открытый агент opencode (+5.9k), мета-harness ruflo (+3.0k) и единственный файл CLAUDE.md в andrej-karpathy-skills (+2.9k).

04Память переходит от одного агента к команде

context-mode из недели выпал, вместо него ai-memory (+3.3k): общая память для двадцати с лишним harness, передача задачи между агентами и сервер для команды с аудит-логом. Хранилище — git-вики из обычных .md, без векторной базы. graphify (+6.9k) тоже обходится без векторов: строит граф кода через AST tree-sitter. hindsight за месяц замедлился: с +27.6k до +25.5k.

05Каталоги плагинов: теперь под роли

После claude-plugins-official неделей раньше в топ вошли knowledge-work-plugins (+2.8k) — открытые плагины Anthropic под роли: продажи, поддержка, юристы, финансы, данные. Каждый плагин — это skills, коннекторы, команды и субагенты.

06Месячный топ почти устоялся

Из месяца ушёл только OpenShell, вошёл impeccable (+16.5k), skill дизайна интерфейсов. VoiceStudio разогнался с +42.0k до +51.0k, hyperframes с +15.4k до +19.2k, freellmapi с +10.1k до +13.0k.

Что может пригодиться аналитической платформе

Граф схем и кода для Text2SQL

graphify превращает код, документы, SQL-схемы и конфиги в граф, который агент запрашивает вместо grep. Код разбирается локально через tree-sitter без LLM, каждая связь помечена EXTRACTED или INFERRED. Документы и PDF идут через модель ассистента или заданный ключ API — в закрытом контуре это стоит направить на свою модель. Есть платная облачная версия, базовая — локальная.

Общая память агентов команды on-prem

ai-memory держит память на сервере, который вы поднимаете сами: знания делятся на уровне проекта, личные передачи задач остаются личными, вход для нескольких пользователей и аудит-лог — без платного тарифа. Источник правды — .md-файлы в git, база пересобирается из них. Удобно, когда одну задачу ведут разные агенты и люди.

Плагин data как образец

В knowledge-work-plugins есть плагин data: SQL, статистика, дашборды и проверка результата перед отправкой, коннекторы Snowflake, Databricks, BigQuery и другие. Готовые коннекторы облачные, но саму структуру — skills, команды, субагенты — можно взять за образец для своего аналитического агента.

Параллельные попытки агентов в worktree

orca раздаёт один запрос пяти агентам, каждому в отдельный git worktree, и даёт сравнить результаты и слить лучший. Агентов можно запускать на удалённой машине по SSH. Подходит, чтобы сравнивать harness на одной задаче, например на генерации SQL.

Аудит LLM-приложения — всё ещё в силе

security-audit-skill повторные прогоны делает накопительными: берёт прошлые ledger и findings, добивает пробелы и перепроверяет изменившийся код. Его можно встроить в регулярный цикл, а не запускать разово. Отдельный файл AI-AND-LLM.md покрывает prompt injection, агентов, инструменты и обработку вывода.

Можно пропустить: ComfyUI, hyperframes, VoiceStudio и artcraft — картинки, видео и голос; ghidra, rea и AnyPS5 — реверс-инжиниринг и игры; impeccable — дизайн фронтенда; freellmapi собирает бесплатные облачные тарифы «только для личных экспериментов».
