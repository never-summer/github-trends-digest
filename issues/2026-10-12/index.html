Главные сдвиги

01Реверс-инжиниринг собрал рекорд

rea набрал +127.0k при 131862 звёздах всего — почти весь рост пришёлся на одну неделю, и это в восемь с лишним раз больше, чем у прошлого лидера VoiceStudio (+14.7k). Это один MCP-сервер, через который агент без исходников разбирает нативные бинарники, Electron-приложения, сборки .NET и сайты и объясняет, как устроена функция.

02Недельный топ сменился почти целиком

Из прошлой десятки остались только hyperframes (вырос с +3.1k до +4.2k) и openrig (замедлился с +4.3k до +2.0k). Ушли VoiceStudio, hindsight, paperclip, ponytail, ai-engineering-from-scratch, Agent-Reach, impeccable и yoinks. Прошлая волна теперь видна в месячном топе: VoiceStudio возглавил его (+36.0k), paperclip вырос с +17.4k до +20.0k.

03Агенты уходят в прикладные инженерные задачи

Рядом с rea в недельном топе e2e (+6.4k) — агент проходит веб- или мобильное приложение по цели, записанной на естественном языке, — и text-to-cad (+2.5k), который генерирует 3D-модели, чертежи и проверки на технологичность. rea и text-to-cad ставятся как MCP или плагин к уже существующим агентам.

04Одиночные skills уступают наборам

Из месячного топа выпали ponytail (был первым с +30.5k), archify и i-have-adhd. Вместо них — наборы: agent-skills (+11.9k за месяц) с девятью командами на весь цикл разработки, а в недельном топе mattpocock/skills (+10.3k) и официальные плагины cursor/plugins (+1.1k).

05Память сменила лидера недели

hindsight ушёл из недельного топа, но в месячном вырос с +23.2k до +25.2k. В неделю вошёл claude-mem (+3.8k): он записывает действия агента, сжимает их в семантические сводки и подмешивает их в следующие сессии.

06Локально: от голоса к большим моделям

В месячный топ вошёл colibri (+13.7k) — запуск MoE-моделей на сотни миллиардов параметров без GPU: в RAM держится часть, нужная на токен, эксперты читаются с диска. В README пример — GLM-5.2 на 744B в int4 на CPU с резидентной памятью 9.9 GB.

Что может пригодиться аналитической платформе

E2E-тесты дашбордов на естественном языке

e2e описывает шаг теста целью на естественном языке, агент проходит приложение, а результат проверяется обычными локаторами. Записанные действия при следующих прогонах воспроизводятся без вызова модели, пока приложение не изменилось; модель можно взять свою, в том числе локальную, — подходит для регрессии интерфейсов дашбордов в закрытом контуре.

Ревью SQL с меньшим расходом токенов

open-code-review вырос в месячном топе с +22.1k до +24.1k. По замеру авторов, с той же моделью он выигрывает у Claude Code по precision и F1 и тратит около 1/9 токенов, но recall ниже — сознательный выбор в пользу меньшего шума. Для ревью на своей модели с ограниченным бюджетом это прямой аргумент.

Ponytail перемерили на большой выборке

В прошлом выпуске замер ponytail был на 12 задачах. Ponytail 5 проверили на 39 задачах, включая реальный репозиторий FastAPI + React, на Opus 5.5 по 5 прогонов: на 53% меньше кода, на 41% меньше времени, рискованная логика уходит с тестом в 98% случаев против 68% без skill. Шесть задач безопасности, включая SQL injection, прошли во всех 30 прогонах.

Skills на весь цикл разработки

agent-skills даёт девять команд от /spec и /plan до /review и /ship, каждая включает нужные skills. Альтернатива — mattpocock/skills: небольшие композируемые skills, которые работают с любой моделью и правятся под себя. Годятся как основа общих правил для агентов команды платформы.

Большая модель в закрытом контуре без GPU

colibri запускает MoE-модели на CPU, читая экспертов с диска. Минимум по README — 8 GB RAM и 22 GB на диске для самой маленькой модели; среди движков GLM, Kimi K3, DeepSeek V4 Flash, Qwen3.6 и Qwen3-Coder. Скорость на своём железе для Text2SQL нужно замерить до выводов.

Память между сессиями — проверить, где она хранится

claude-mem сохраняет наблюдения агента между сессиями. В инструкции по установке по умолчанию стоит хостинговая память CMEM Pro, а локальный режим включается флагом --provider host — для закрытого контура подходит только он.

Можно пропустить: AnyPS5, openGym и gods-eye-view — игры, фитнес и витрина публичных данных; rea разбирает чужие приложения, платформе он не нужен; hyperframes, text-to-cad и VoiceStudio — видео, CAD и голос.
