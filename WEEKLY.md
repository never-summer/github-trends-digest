# Еженедельный выпуск: инструкция для агента

Ты готовишь очередной выпуск дайджеста https://never-summer.github.io/github-trends-digest/ —
обзор самых звёздных репозиториев GitHub и того, куда движется AI-индустрия.
Выпуск публикуется сразу, без ревью человеком, поэтому **ни одной цифры и ни одного факта
не из источников**. Лучше короче, чем с выдумкой.

Читатель — русскоязычный инженер или руководитель аналитической платформы
(Text2SQL, дашборды, лейкхаус на S3/Ozone, закрытый контур и on-prem, агенты для команды).
Не упоминай конкретных работодателей, банки и внутренние системы читателя.

## Шаги

1. **Дата выпуска** — сегодняшняя дата по UTC, `YYYY-MM-DD`. Если `data/issues/<дата>.json`
   уже существует, ничего не делай и заверши работу.

2. **Данные.** Запусти `python3 fetch_trending.py show`. Он ничего не скачивает: срез GitHub Trending
   за сегодня уже лежит в `data/snapshots/<дата>.json` — его в 05:00 UTC коммитит GitHub Action
   `fetch-trending` (облачной сессии github.com/trending недоступен, не пытайся его открыть).
   Скрипт печатает JSON с тремя топами: `week` (прирост звёзд за 7 дней), `month` (за 30 дней),
   `quarter` (сумма недельных приростов по срезам текущего календарного квартала;
   поле `snapshots` — сколько недель в сумме) и `readmes` — начало README каждого проекта из топов.
   Если скрипт упал (нет среза за сегодня) или топы пустые — **не публикуй ничего**:
   заверши работу и в финальном сообщении опиши ошибку.

3. **Разберись в проектах** по `readmes` из вывода скрипта. Описание в топе пиши по README,
   а не по названию. Если README пустой и по описанию из Trending непонятно, что это, —
   так и пиши коротко, не додумывай.

4. **Сравни с прошлым выпуском** — самый свежий файл в `data/issues/`. Тренды — это то, что
   *изменилось*: кто вырос, кто выпал, какие новые категории появились, что подтвердилось
   или опровергло прошлые выводы. Не переписывай прошлый выпуск своими словами.

5. **Напиши `data/issues/<дата>.json`** по образцу `data/issues/2026-09-30.json`:

   | поле | что писать |
   |---|---|
   | `date` | дата выпуска, совпадает с именем файла |
   | `title` | короткий заголовок выпуска, 2–6 слов, о главном сдвиге недели |
   | `lede` | 1–2 предложения: главное за неделю |
   | `tops.week` / `tops.month` / `tops.quarter` | `caption` + до 10 `items` из вывода скрипта, в том же порядке |
   | `items[].repo` | `owner/name` ровно как в выводе скрипта |
   | `items[].description` | по-русски, одна строка до ~80 знаков: что это и зачем |
   | `items[].category` | необязательно; одно из: `harness`, `skill`, `память`, `оркестрация`, `RAG`, `безопасность`, `локальные LLM`, `данные`, `модель`, `инструмент`. Пусто, если не подходит |
   | `items[].stars` | неделя и месяц — `+12.9k` (прирост из `stars_gained`, одна цифра после точки, до 1000 — как есть: `+870`); квартал — `≈71k` |
   | `trends` | 4–7 пунктов `{title, body}` |
   | `picks` | 3–6 пунктов `{title, body}`, чем полезно аналитической платформе; идеи «на радар» — с `"radar": true` |
   | `skip` | одна строка: что из топа можно не смотреть и почему |

   Подписи топов (`caption`):
   - неделя: `Последние 7 дней · на 30 сентября`
   - месяц: `Последние 30 дней · на 30 сентября`
   - квартал: `Квартал с 1 октября · сумма 3 недельных срезов` (число — поле `snapshots`).
     Если срез всего один, добавь: `· квартал только начался`.

   В `body` трендов, пиков и в `skip` имена проектов оборачивай в обратные кавычки:
   `` `hindsight` `` — на странице они станут плашками. Остальной текст — простой, без HTML
   и без markdown. Стиль: коротко, по делу, без канцелярита и «AI-шлака»,
   без восклицаний и слов «революционный», «мощный», «game-changer».

6. **Собери сайт:** `python3 build.py`. Он проверяет JSON; если упал — исправь данные и
   запусти снова. Не правь `build.py`, `fetch_trending.py`, `style.css` и этот файл.

7. **Опубликуй:**
   ```
   git add data/ index.html issues/
   git commit -m "Weekly digest <дата>"
   git push origin HEAD:main
   ```
   GitHub Pages пересоберёт сайт за минуту-две.

8. В финальном сообщении — заголовок выпуска, топ-3 недели и ссылка на страницу.
