Главные сдвиги

01Реверс-инжиниринг не остыл, а ускорился

rea вырос с +127.0k до +229.3k за неделю, всего у него 329144 звезды. Вслед за ним в недельный топ вошла ghidra (+7.6k, за месяц +12.0k) — по README rea нативный анализ идёт через уже установленные Hopper, Ghidra или IDA. Прошлый вывод про рекорд подтвердился: это не разовый всплеск.

02Безопасность агентов вошла в месячный топ

Новая категория: security-audit-skill (+19.1k за месяц) от Cloudflare ведёт аудит в шесть фаз, и каждую находку перепроверяет отдельный агент, который пытается её опровергнуть. OpenShell (+8.0k) от NVIDIA запускает агентов в песочнице: доступ к файлам, системным вызовам и сети ограничен политикой, а реальные ключи агент не видит.

03Плагины собираются в каталоги

В недельный топ вошёл официальный каталог claude-plugins-official (+4.8k), cursor/plugins ускорился с +1.1k до +1.7k. Выпавший из недели mattpocock/skills теперь ставится в Claude Code как раз через этот каталог. Прошлый тренд «наборы вместо одиночных skills» продолжился: наборы распространяются через маркетплейсы.

04Экономия контекста вместо памяти

claude-mem выпал из недельного топа, его место занял context-mode (+4.1k): вывод инструментов остаётся в песочнице, события сессии пишутся в SQLite и подтягиваются поиском по FTS5. По замеру авторов 315 KB превращаются в 5.4 KB. hindsight в месячном топе вырос с +25.2k до +27.6k.

05Визуальный вывод агентов

Новые в недельном топе — artcraft (+16.4k), IDE для генерации картинок и видео со сценами в 3D, и diagram-design (+7.9k), skill, который рисует диаграммы одним файлом HTML + SVG. hyperframes ускорился с +4.2k до +5.9k.

06Месячный топ сменился наполовину

Из месячного топа ушли open-code-review, colibri, agent-skills и gods-eye-view. Лидеры укрепились: VoiceStudio вырос с +36.0k до +42.0k, paperclip с +20.0k до +23.3k. Новые — security-audit-skill, ghidra, freellmapi и OpenShell.

Что может пригодиться аналитической платформе

Аудит безопасности кода платформы агентами

security-audit-skill раскладывает репозиторий на карту архитектуры и границ доверия, раздаёт участки изолированным агентам, а каждую находку отдаёт свежему верификатору. Результат — confirmed, needs_validation и rejected в findings.json, проверенном по схеме. Есть отдельные классы атак для LLM-приложений: prompt injection, агенты и инструменты, обработка вывода — по делу для Text2SQL.

Песочница для агентов команды

OpenShell ограничивает каждого агента политикой на файлы, системные вызовы и сеть, а ключи подставляет только в запросы к разрешённым адресам. Изменение политики, открывающее новый доступ, проверяется формально и ждёт ревью человека. Нужен Linux или macOS на Apple Silicon и Docker, Podman или виртуализация — подходит для on-prem.

Большие выборки не в контекст агента

context-mode держит сырой вывод инструментов вне контекста, а агент пишет скрипт, который считает и печатает только итог. Для аналитического агента это прямой способ не тащить результаты запросов в окно модели. Данные сессии хранятся локально в SQLite; без --continue они удаляются сразу.

Диаграммы архитектуры одним файлом

diagram-design по запросу на естественном языке рисует схему архитектуры, квадрант или sequence-диаграмму в один HTML-файл, умеет импортировать из draw.io, Mermaid и Excalidraw. Что skill отправляет по сети, описано в PRIVACY.md — для закрытого контура это стоит прочитать до установки.

Каталог плагинов — не гарантия

В claude-plugins-official прямо сказано: Anthropic не контролирует MCP-серверы и файлы внутри плагинов и не может проверить, что они не изменятся. Для общих настроек агентов команды нужен свой список проверенных плагинов.

Можно пропустить: rea, ghidra и AnyPS5 — реверс-инжиниринг и игры; artcraft, hyperframes и VoiceStudio — картинки, видео и голос; ai-job-search — поиск работы; freellmapi собирает бесплатные облачные тарифы и сам помечен «только для личных экспериментов».
