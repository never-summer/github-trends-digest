Главные сдвиги

01Голос вышел на первое место

VoiceStudio вырос с +12.7k до +14.7k за неделю и возглавил топ — единственный из прошлой тройки лидеров, кто ускорился. Аргумент тот же: клонирование голоса, дубляж и диктовка на своём железе, удалённые сервисы опциональны, есть локальный API и MCP для агентов.

02Память и оркестрация остывают, но держатся

hindsight замедлился с +17.4k до +10.6k, paperclip — с +12.9k до +8.7k. Оба остались на втором и третьем местах недели, а в месячном топе paperclip поднялся с +14.6k до +17.4k. Прошлый рывок памяти оказался волной, а не устойчивым темпом, — но и не провалом.

03Новый претендент на команды агентов

openrig набрал +4.3k при 5079 звёздах всего, то есть почти весь рост пришёлся на эту неделю. Идея — команда агентов в YAML, Claude Code и Codex в одном rig с ролями, общим контекстом и закреплённой работой. Из недельного топа при этом выпал orca, так что тема держится, а проекты в ней меняются.

04Skills вернулись в недельный топ

Прошлый вывод «skills держат месяц, но не неделю» не подтвердился: ponytail (+7.9k) вошёл в недельный топ и возглавил месячный (+30.5k), impeccable вырос с +2.6k до +4.2k, hyperframes (+3.1k) ставится как плагин со skills. archify при этом опустился в месячном топе с +45.2k до +30.2k.

05Агенту — доступ к внешнему вебу

Agent-Reach (+4.8k) одной командой даёт агенту чтение веба, YouTube, RSS, Reddit, Twitter, Bilibili и Xiaohongshu без платных API, с диагностикой agent-reach doctor и cookies только на локальной машине. Рядом в топе yoinks — загрузка видео из терминала поверх yt-dlp, но уже для людей, не для агентов.

06Офисные и отраслевые проекты выпали

Из недельного топа ушли univer, CLI-Anything, financial-services, orca и WeKnora. WeKnora зато поднялся в месячный топ (+10.9k), вытеснив OpenMAIC.

Что может пригодиться аналитической платформе

База знаний в закрытом контуре

WeKnora в README прямо пишет, что LLM, векторные базы и хранилища заменяемы, а развернуть можно локально или в частном облаке, оставив данные у себя; среди вендоров есть Ollama. Плюс RBAC по рабочим пространствам с аудит-логом и синхронизация с Confluence и GitLab — кандидат для поиска по документации платформы.

Меньше кода в пайплайнах от агентов

ponytail — один промпт-skill, который заставляет агента сначала проверить, нужен ли код, нет ли его уже в репозитории, в stdlib или в установленных зависимостях. Авторы заявляют ~54% меньше кода на замере в Claude Code (12 задач, Haiku 4.5, n=4) — выборка маленькая, стоит проверить на своих задачах.

Проверка вёрстки дашбордов без LLM

impeccable — дизайн-skill для фронтенда, а его CLI и расширение браузера запускают 61 детерминированное правило без LLM и API-ключа. Это можно гонять и в закрытом контуре по интерфейсам дашбордов и внутренних инструментов.

Ревью SQL и кода своей моделью

open-code-review держится в месячном топе (+22.1k): работает с любым настроенным endpoint модели, оставляет построчные замечания, в правилах есть SQL injection, а ocr scan ревьюит целые файлы без diff — для аудита унаследованного кода.

Команда агентов из Claude Code и Codex

openrig описывает команду агентов в YAML и поднимает её одной командой. Перед установкой README просит прочитать, что он меняет на машине: пишет хуки провайдеров и настройки доверия к рабочему пространству. Пока на радар.

Можно пропустить: VoiceStudio и yoinks — голос и видео, к аналитике не относятся; Agent-Reach завязан на внешние соцсети и в закрытом контуре бесполезен; gods-eye-view и ai-engineering-from-scratch — витрина публичных данных и курс.
